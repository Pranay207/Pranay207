**Seeking:** Applied AI Engineer, Machine Learning Systems Engineer, Backend AI Engineer, and Full-Stack AI roles.

Software engineer specializing in deterministic compliance engines, forensic financial platforms, and air-gapped document intelligence. My engineering focus is eliminating LLM hallucinations in critical workflows by decoupling statistical language models from deterministic verification policies (AWS Cedar), guaranteeing auditability and strict data boundaries.

### Core Engineering Invariants

* **Deterministic Rule Evaluation:** Statistical models propose structured entities; formal policy engines (AWS Cedar) execute compliance rules to eliminate legal and financial hallucination.
* **Source-Linked Auditability:** Every model inference, extracted cell, or dispute record maintains cryptographic or bounding-box provenance linked directly to source ground truth.
* **Air-Gapped Data Privacy:** Document intelligence pipelines run on-device via local OCR routines to prevent confidential client data from leaking to third-party endpoints.
