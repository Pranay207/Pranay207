### Engineering Thesis
Most generative AI applications break down in production because they rely on probabilistic guesswork for mission-critical logic. I design systems where legal and financial logic is evaluated deterministically via formal verification engines (AWS Cedar), document extraction runs on-device without data leakage (RapidOCR), and every output is anchored to an immutable, court-admissible audit trail.

### Production Systems

#### 1. ATP Fraud Intelligence Platform
**Financial Forensics & Law Enforcement Intelligence** • [Live System](https://atp-fraud-intelligence.vercel.app) • [Source Code](https://github.com/Pranay207/ATP-Fraud-Intelligence-System)
Financial fraud detection and network topology platform built for law enforcement agencies to uncover money-mule rings and trace illicit fund routing across shell accounts. Ingests high-volume transaction records into an interactive graph visualization layer with localized clustering heuristics and generates court-ready forensic digital evidence trails.
`FastAPI` • `React` • `TypeScript` • `Network Graph Analysis` • `Behavioral Analytics` • `Risk Scoring`

#### 2. DeFang: Statutory Contract Engine
**Deterministic Legal Compliance & Risk Scanner** • [Live Engine](https://defang-bharat.vercel.app) • [Source Code](https://github.com/Pranay207/DeFang)
Zero-hallucination compliance platform formally validating Indian rental agreements, tech employment bonds, and freelance MSAs against statutory labor laws. Replaces generative guessing with formal policy verification using AWS Cedar and Strands Agent SDK, coupled with AWS OpenSearch for precedent retrieval and Finch container execution.
`AWS Cedar` • `AWS OpenSearch` • `Strands Agent SDK` • `Python` • `FastAPI` • `Finch Containers`

#### 3. ProofPilot AI: Merchant Dispute Defense
**Autonomous Payment Arbitrations & Courier Telemetry** • [Live Platform](https://proofpilot-ai.onrender.com/) • [Source Code](https://github.com/Pranay207/ProofPilot-AI)
Automated chargeback defense platform for Razorpay merchants. Intercepts dispute webhooks, synchronously queries Shiprocket courier telemetry for real-time proof of fulfillment, and automatically compiles cryptographic evidence dossiers to win payment gateway arbitrations within the 48-hour deadline.
`Node.js` • `PostgreSQL` • `Prisma ORM` • `Webhook Infrastructure` • `React` • `Fintech`

#### 4. Truecell: Local-First Document Intelligence
**Air-Gapped Table Extraction & OCR** • [Source Code](https://github.com/Pranay207/Truecell)
Privacy-preserving document parser converting unstructured PDFs, payroll sheets, and camera scans into formula-verified Excel workbooks. Runs entirely on-device using optimized RapidOCR to guarantee zero external cloud exfiltration, mapping every extracted cell back to its source bounding-box pixel coordinates.
`Python` • `RapidOCR` • `FastAPI` • `Table Geometry Extraction` • `Local-First` • `AGPL-3.0`
