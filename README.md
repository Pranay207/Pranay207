## Core Production Systems

### 1. ATP Fraud Intelligence Platform
*Financial Crime Forensics & Transaction Topology for Law Enforcement*  
**System URL:** https://atp-fraud-intelligence.vercel.app • **Repository:** [Pranay207/ATP-Fraud-Intelligence-System](https://github.com/Pranay207/ATP-Fraud-Intelligence-System)
* **Problem:** Investigating financial fraud across layered shell accounts and mule rings typically requires weeks of manual transaction cross-referencing.
* **Architecture:** Ingests high-throughput transaction streams into an interactive graph topology engine. Employs localized clustering heuristics to isolate circular fund routing and automatically generates court-admissible forensic PDF dossiers with verifiable chains of custody.
* **Tech:** Python, FastAPI, React, TypeScript, Graph Topology Engine, Behavioral Anomaly Scoring

### 2. DeFang: Statutory Policy Engine
*Deterministic Contract Risk Auditing via Formal Verification*  
**System URL:** https://defang-bharat.vercel.app • **Repository:** [Pranay207/DeFang](https://github.com/Pranay207/DeFang)
* **Problem:** Standard LLMs hallucinate when evaluating complex employment bonds, commercial leases, and MSAs against state labor codes and statutory legislation.
* **Architecture:** Decouples text extraction from decision-making. Entity parsing is delegated to Strands Agent SDK, while compliance pass/fail verification is executed mathematically against formal **AWS Cedar policies**, backed by AWS OpenSearch precedent indexing in Finch container runtimes.
* **Tech:** AWS Cedar, AWS OpenSearch, Strands Agent SDK, Python, FastAPI, Finch Containers, AWS SAM

### 3. ProofPilot AI
*Autonomous Merchant Dispute & Chargeback Defense Platform*  
**System URL:** https://proofpilot-ai.onrender.com • **Repository:** [Pranay207/ProofPilot-AI](https://github.com/Pranay207/ProofPilot-AI)
* **Problem:** E-commerce merchants lose high-value payment arbitrations due to missed 48-hour evidence submission deadlines.
* **Architecture:** Event-driven dispute defense infrastructure for Razorpay merchants. Intercepts payment dispute webhooks, synchronously cross-references real-time Shiprocket courier fulfillment telemetry, and compiles cryptographic evidence binders before gateway windows close.
* **Tech:** Node.js, TypeScript, PostgreSQL, Prisma ORM, Idempotent Webhook State Machine, React

### 4. Truecell Document Intelligence
*Air-Gapped Table Extraction & Formula Validation*  
**Repository:** [Pranay207/Truecell](https://github.com/Pranay207/Truecell)
* **Problem:** Cloud-hosted OCR services risk data exfiltration when parsing sensitive payrolls, financial filings, and medical bills.
* **Architecture:** Operates 100% on-device with zero cloud egress using RapidOCR. Maps all extracted cell values directly to source pixel coordinates, enforcing deterministic mathematical proofs over table geometries before compiling into formula-verified Excel sheets.
* **Tech:** Python, RapidOCR, FastAPI, Geometric Layout Analysis, Local-First Engine, AGPL-3.0
